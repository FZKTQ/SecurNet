# Архитектура и сопровождение ИС «SecurNet»

## Компоненты системы
1. **Источники телеметрии:** сетевые сенсоры (NetFlow/DPI/IDS), агенты конечных точек (EDR, Syslog, Windows Event Log), сканер уязвимостей CVE.
2. **Шина сбора и нормализации:** Apache Kafka + Logstash (целевая производительность — от 15 000 EPS).
3. **Ядро анализа и хранения:** модуль корреляции и ML (UEBA), ClickHouse (потоковые события), PostgreSQL (карточки инцидентов и RBAC).
4. **Модуль реагирования (SOAR):** автоматические и полуавтоматические плейбуки с поддержкой отката ошибочных блокировок.
5. **Клиентский слой:** API Gateway (REST/WebSocket, TLS 1.3, JWT) и веб-консоль SOC-аналитика.

## Регламент версионирования
- Основная стабильная ветка: `main`.
- Новая функциональность разрабатывается в изолированных ветках `feature/<название>` и вливается через `git merge --no-ff`.
- Релизы маркируются семантическими тегами (`v1.0.0`, `v1.1.0` и т. д.).
