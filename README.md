# SecurNet — Инновационная система кибербезопасности

Веб-консоль мониторинга и реагирования на инциденты информационной безопасности (SIEM / SOAR / UEBA), разработанная в рамках учебной практики по профессиональному модулю **ПМ.06 «Сопровождение информационных систем»** (специальность 09.02.07 «Информационные системы и программирование»).

## Основные возможности веб-консоли
- **Мониторинг потока событий (EPS):** отслеживание телеметрии в реальном времени с графиком событий и аномалий.
- **Корреляция и UEBA-анализ:** классификация инцидентов по критичности, поиск и фильтрация событий безопасности.
- **Модуль реагирования SOAR:** выполнение плейбуков (блокировка IP, изоляция хоста, закрытие инцидента и безопасный откат блокировки).
- **Сканер уязвимостей (CVE):** контроль критических уязвимостей узлов с возможностью запуска патчинга.
- **Симуляция кибератаки и экспорт отчета:** тестирование реакции системы и выгрузка журнала инцидентов в формате JSON.

## Структура проекта
```text
SecurNet/
├── index.html            # Главная страница веб-консоли SOC-аналитика
├── styles.css            # Стили интерфейса (темная тема SOC)

│   └── architecture.md   # Описание архитектуры и регламент сопровождения (Docs-as-Code)
├── .gitignore            # Исключения Git (секреты, логи, системные файлы)

```

## Запуск проекта
1. **Локально:** откройте файл `index.html` в любом современном браузере.
2. **На GitHub Pages:** в настройках репозитория откройте **Settings → Pages**, выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
